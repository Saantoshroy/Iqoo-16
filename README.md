# 🔴 iQOO 16 — Gaming Concept Website

A premium, responsive **black\-and\-red gaming\-inspired landing page** built with HTML, CSS, and JavaScript by **AABHI DEV**\.

> **Disclaimer:** This is an independent fan-made concept project. It is not an official iQOO website and does not claim to show official iQOO 16 specifications.

## ✨ Features

- Premium dark UI with neon\-red glow effects
- Animated floating background particles
- Interactive product card with tap/click expansion
- Desktop 3D tilt effect
- CSS\-built smartphone concept visual
- Responsive layout for desktop, tablet, and mobile
- Smooth scrolling and reduced\-motion accessibility support
- No framework or package installation required

## 🛠️ Built With

- **HTML5** — page structure
- **CSS3** — layout, responsive styles, glow effects, and animations
- **JavaScript** — interactive card, floating particles, and 3D tilt
- **Google Fonts** — Orbitron and Poppins

## 🚀 Run Locally

1. Download or clone this repository\.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder\.
3. Open `index.html` in a modern browser\.

No build tools or dependencies are required\. An internet connection is only needed to load Google Fonts\.

## 🌐 Deploy with GitHub Pages

1. Push these project files to a GitHub repository\.
2. Open the repository’s **Settings**\.
3. Select **Pages** from the sidebar\.
4. Under **Build and deployment**, choose **Deploy from a branch**\.
5. Select your main branch and the root &#40;`/`&#41; folder, then save\.
6. Wait for GitHub Pages to publish the site and open the URL shown in the Pages settings\.

## 🎨 Customization

- Change colors in the `:root` variables at the top of `style.css`\.
- Edit headings and page content in `index.html`\.
- Adjust animations and interaction behavior in `script.js`\.
- Update the author credit from `santosh Roy ` if needed\.
